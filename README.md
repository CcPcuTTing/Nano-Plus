# Nano Plus

A lightweight terminal text editor written in C++.

Nano Plus aims to provide a simple, fast and free text editing experience.

## Version

Current version: v0.1 Alpha

## Features

- [x] Text input
- [x] Delete lines
- [x] Save .txt files
- [x] Save .nap files

g++ src/main.cpp -o nanoplus
